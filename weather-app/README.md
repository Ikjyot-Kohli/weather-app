# 🌦️ Advanced Weather App

This is an **Advanced Weather App** built using **React, Vite, and Tailwind CSS**.  
The application shows **real-time weather data and forecast** for any city searched by the user.

---

## 📌 Project Features

- Search weather by **city name**
- Show **current temperature**
- Show **weather condition** (Clear, Cloudy, Rain, etc.)
- Display **humidity, wind speed, and heat index**
- Show **multi-day weather forecast**
- Handle **invalid city errors**
- Clean and modern **Weather Dashboard UI**

---

## 🛠️ Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript
- Weather API


## ▶️ How to Run the Project

1. Install dependencies:
   npm install

2. Start the project:
   npm run dev

3. Open in browser:
   Ctrl + click the link http://localhost:5173/
